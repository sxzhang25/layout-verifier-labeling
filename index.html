Layout Labeling

Thank you for helping with this user study! This should take about 15-20 minutes total. When you are done you may close the window.

Instructions

You will be shown computer-generated layouts and asked to judge each one True or False. The work is split into separate layout tasks, with 20 layouts in each task.

At the top of each section you will find a task description describing the criteria for the layouts; and a dev set of examples: layouts for that same task that have already been labeled, each shown with its True or False verdict and a note explaining why.

For each unlabeled layout, assign True or False based on the task description and the dev-set examples.

Shortcuts

  1. You can use t for True and f for False. Arrow keys move between layouts, and u resets a verdict.
  2. Your answers save as you go. You can stop and come back to where you left off.
  3. You can move between sections at any time using the links at the top.
